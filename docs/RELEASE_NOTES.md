# Aster source foundation

This release contains source code, a pinned Chromium overlay, independently tested core modules, citation metadata/exports, standalone research-library, planner, flashcard, dataset, chart, AI-consent and backup modules (see docs/API.md), build scripts and CI configuration. It does not contain a runnable Aster browser or native installers.

The overlay targets official Chromium 157.0.8103.50. Native Split Search and workspace snapshot integration is written but has not been compiled or launched. Core tests and metadata tests run independently. See docs/STATUS.md for executed evidence, feature boundaries and remaining work.

Do not use this milestone as a supported daily browser or assume its Chromium pin stays security-current automatically.
